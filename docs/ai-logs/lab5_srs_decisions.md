## Відхилено

| Зауваження | Причина |
|---|---|
| OWASP ZAP, testssl.sh | Прибрано зі стека в ЛР№4 через обсяг; TLS перевіряється тестом Node.js-клієнта, API — Schemathesis |
| Chaos Mesh | Прибрано в ЛР№4; відмови моделюються Toxiproxy і `kubectl delete pod` |
| Kyverno, Conftest/OPA, cosign admission | Прибрано в ЛР№4; достатньо вбудованого Pod Security Admission і `trivy config` |
| Crypto-shredding за суб'єктом даних (SEC-09) | Строк зберігання в брокері ≤ 30 діб уже виконує 30-денний строк стирання GDPR; окремий ключ на суб'єкт ускладнює модель без впливу на мету дослідження |
| A4-26 WCAG 2.2 | Портал допоміжний, поза об'єктом дослідження |
| A4-27 | Зафіксовано як поза обсягом (розділ 1.2) |
